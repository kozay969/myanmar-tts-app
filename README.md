# Myanmar AI Text-to-Speech (TTS) Web Application

ဤသည်မှာ Microsoft Edge Neural TTS Engine ကို အသုံးပြု၍ မြန်မာစာသားများကို သဘာဝကျပြီး ပီသလှသော လူသားတစ်ဦးကဲ့သို့ အသံထွက်များအဖြစ် အလိုအလျောက် ပြောင်းလဲပေးသည့် Streamlit Web Application ဖြစ်သည်။

## 🚀 ထူးခြားချက်များ (Features)
- **High-Fidelity Neural Voices:** Microsoft ၏ နောက်ဆုံးပေါ် Deep Learning မော်ဒယ်များကို သုံးထားသဖြင့် အသံထွက် အလွန်သဘာဝကျသည်။
- **Gender Selection:** ကျား/မ (အမျိုးသားအသံ 'သီဟ' နှင့် အမျိုးသမီးအသံ 'နီလာ') စိတ်ကြိုက် ရွေးချယ်နိုင်သည်။
- **Zero Terminal Deployment:** ဖုန်းဖြင့်သာ စီမံခန့်ခွဲမည့်သူများအတွက် Terminal သုံးရန်မလိုဘဲ GitHub Web Interface နှင့် Streamlit Cloud တို့ဖြင့် တိုက်ရိုက် ချိတ်ဆက်အသုံးပြုနိုင်သည်။
- **Resource Management:** အသံထုတ်ပြီးလျှင် ဆာဗာ၏ နေရာလွတ်ကို သန့်ရှင်းစေရန် ယာယီဒေတာများကို အလိုအလျောက် ဖျက်ပစ်သည်။
